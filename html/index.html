Docker Compose

Guía rápida y compacta

1. ¿Qué es?

Una herramienta de Docker que permite definir y ejecutar aplicaciones multi-contenedor mediante un único archivo en formato YAML.

2. ¿Para qué se usa?

Para simplificar entornos complejos (p. ej. Web + Base de datos). En lugar de levantar cada contenedor a mano, inicias todo tu sistema con un solo comando.

3. ¿Cómo se utiliza?
docker-compose.yml
docker-compose.yml 
version: '3.8'
services:
  web:
    image: nginx:alpine
    ports:
      - "8080:80"
  db:
    image: postgres:15-alpine
    environment:
      POSTGRES_PASSWORD: secret123
docker compose up -d

Crea e inicia todos los servicios en segundo plano (-d).

docker compose down

Detiene y elimina contenedores, redes y volúmenes creados.

💡 Consejo: Guarda el código en un archivo llamado docker-compose.yml y ejecuta los comandos en esa misma carpeta.
